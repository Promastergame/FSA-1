# FSA 1 (Fast System App 1)

<img src="assets/badge.svg" alt="Zig 0.18.0 | Win32 / GDI+ | Zero Deps" height="24">

Системный оверлей для Windows, позволяющий вставлять изображения из буфера обмена (`Ctrl + V`) напрямую в открытые папки Проводника и на Рабочий стол в виде файлов.

Написан на чистом Zig (только `std`) поверх Win32 API, COM (`IShellWindows` / `IFolderView`), DWM и GDI+. Без иконок в трее, без браузерных движков и сторонних зависимостей.

[English version](README.md)

## Задача и решение

Стандартный Проводник Windows игнорирует `Ctrl + V`, если в буфере обмена лежат пиксели изображения (`CF_BITMAP` / `CF_DIB` после скриншота `Win + Shift + S` или копирования картинки из браузера), а не скопированный файл (`CF_HDROP`).

`fsa1.exe` перехватывает `Ctrl + V`, проверяет наличие картинки в буфере и активность окна Проводника или Рабочего стола, через COM получает путь активной вкладки Explorer и сохраняет файл напрямую в текущую папку. Обычная вставка текста и файлов работает штатно.

## Управление

- **`Ctrl + V` (в Проводнике или на Рабочем столе):** Открывает меню под курсором (либо мгновенно сохраняет файл при включенном автосохранении).
  - Введите имя файла или оставьте поле пустым для сохранения по шаблону (`picture_1`, `picture_2`, ...).
  - Переключение формата (`PNG`, `JPEG`, `BMP`, `TIFF`): `Tab`, стрелки `Влево`/`Вправо` или клик мышью.
  - `Enter` — сохранить, `Esc` (или клик вне окна) — отмена.
- **`Tab + 1` (Глобально):** Открывает меню настроек (автосохранение без меню, шаблон имени, формат по умолчанию, язык интерфейса `Auto` / `EN` / `RU`). Настройки хранятся в реестре `HKCU\Software\FSA\FSA1`.

## Сборка

Требуется Zig `0.18.0` (или `0.17.0`).

```sh
zig build -Doptimize=ReleaseSmall
```

Итоговый файл: zig-out/bin/fsa1.exe.
